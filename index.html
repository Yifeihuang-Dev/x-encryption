What it does

  • AES-256-GCM, chunked streaming.
  • Password derived with PBKDF2.
  • Three factors merged.
  • Header authenticated as AAD.
  • Chunk index & count in AAD.
  • Verify first, decrypt later.
  • Name/type/size stored encrypted.

What it does NOT do

  • No network, no upload, no telemetry.
  • No MD5 / DES / ECB / home-made algorithms.
  • No back door.
  • No promise about SSD deletion.
  • No X.509 chains, no self-extracting executables.

Two honest facts about the third factor

  • A fingerprint never becomes a key.
  • No silent fallback.

File format

[header 88+N] [verify 48] [metaLen 2] [meta N] [chunk0 .. chunkN-1]

Output extension .enc1, certificate .enc1cert.
